# StudySOS

## Overview
StudySOS is a student dashboard designed to help students manage their study schedules effectively. It features an exam countdown, a subject and topic manager, an SOS mode for prioritizing urgent topics, and a progress tracker. The application utilizes local storage to save user data, ensuring that your information is preserved between sessions.

## Features
- **Exam Countdown**: Keep track of upcoming exams with a countdown timer.
- **Subject and Topic Manager**: Add, edit, and delete subjects and topics to organize your study materials.
- **SOS Mode**: Highlight urgent topics that need immediate attention.
- **Progress Tracker**: Monitor your progress on various subjects and topics.
- **Local Storage**: Save your data locally to maintain your settings and progress across sessions.

## Setup Instructions
1. Clone the repository or download the project files.
2. Open the `index.html` file in your web browser to view the dashboard.
3. Ensure that JavaScript is enabled in your browser for full functionality.

## Usage Guidelines
- Use the subject and topic manager to create a structured study plan.
- Set your exam dates to utilize the countdown feature effectively.
- Activate SOS mode for topics that require urgent attention.
- Track your progress regularly to stay motivated and on track.
